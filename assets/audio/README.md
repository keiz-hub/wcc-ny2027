# Background music

Put your music here as **`music.mp3`**. It loops and plays while people browse the site (public pages and `/admin`), including during the New Year show. If the file is missing, a built-in melody plays instead.

- Keep it under about 4 MB (128 kbps MP3 is plenty).
- Use music you have the right to play publicly, and add credits to the page footer if the license asks for them.
- To use a different file name, change `AUDIO.music` in the sound section of `fireworks.js`.
- Sound loads from the website, so it works on GitHub Pages but not when `index.html` is opened straight from a folder.

The three firework sound effects (Bang, Soft pop, Sparkle chimes) are built in and need no files.

Browsers only allow sound after the visitor taps or clicks the page once, so music begins on the first tap.
